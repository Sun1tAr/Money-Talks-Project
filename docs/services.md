# Сервисы Money Talks Project

| Сервис | Ответственность | Порт |
|---|---|---|
| Gateway | Внешние маршруты, регистрация и вход, JWT, `X-User-ID` | 8080 |
| User | Создание и получение пользователей, хранение хэшей паролей | 8083 |
| Account | Счета, денежные ресурсы, исполнение и статус ордеров | 8082 |
| Categories | Категории и типы категорий | 8081 |
| Transaction | Создание и история транзакций, оркестрация операций | 8084 |
| Commons | DTO, исключения, общие заголовки и конфигурация | — |
| Root | Родительский Maven POM с общими версиями | — |

Ссылки на все репозитории находятся в корневом README. Аналитика, use cases и
BPMN-модели — в `MTP-docs`.
